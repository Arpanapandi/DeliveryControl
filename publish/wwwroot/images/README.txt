INSTRUKSI UNTUK LOGO:
=====================

Silakan simpan file gambar logo Anda dengan nama "logo.png" di folder ini.

Gambar logo akan muncul di sidebar aplikasi di atas teks "DCS SYSTEM".

Rekomendasi:
- Format: PNG dengan background transparan
- Ukuran: 200x200 px atau lebih besar (akan disesuaikan otomatis)
- Warna: Logo dengan warna cyan/biru akan terlihat lebih baik dengan efek glow yang sudah diterapkan

Setelah menyimpan file logo.png, refresh halaman aplikasi untuk melihat perubahannya.
