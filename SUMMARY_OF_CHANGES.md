# Summary of Changes: Refined Preparation Schedule List

The floating "Lists" button in the Preparation workflow has been significantly improved.

## Key Features Implemented

1.  **Kanban Progress Fraction:**
    - Replaced the percentage bar with a clear `Actual / Target` fraction (e.g., `2 / 2`).
    - This allows operators to see exactly how many boxes are scanned versus needed.

2.  **Smart Filtering:**
    - **Date Filter:** Easily switch between days.
    - **VIN Search:** Quickly find schedules by typing part of the VIN or Part Number.

3.  **Priority Sorting:**
    - **Top Priority:** Schedules that are "In Progress" or "Preparing".
    - **Medium Priority:** Schedules that are "Scheduled" (Waiting).
    - **Low Priority:** Schedules that are "Completed".

4.  **VIN Visibility:**
    - The "Route / Cycle" column has been replaced with a list of **VINs** contained in the schedule, making it easier to identify the contents.

## How to Test
1.  Open the application and go to the Preparation page.
2.  Click the floating list button (bottom right).
3.  Observe the new filters at the top of the modal.
4.  Verify the list is sorted correctly (active items at the top).
5.  Type a VIN to test the filter.
