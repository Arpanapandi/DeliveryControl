## 📋 Aturan Kerjasama

Untuk memastikan pengembangan berjalan sesuai keinginan USER, berikut adalah aturan mainnya:

### 1. Mode Planning (Default)
- **Prosedur**: Saya akan selalu membuat `implementation_plan.md` terlebih dahulu.
- **Tujuan**: Diskusi detail mengenai perubahan kode, logika, atau desain.
- **Eksekusi**: Saya **TIDAK AKAN** merubah kode sebelum USER memberikan persetujuan (approval).

### 2. Mode Fast
- **Trigger**: USER memberikan instruksi dengan kata kunci "**Fast**" atau "**Cepat**".
- **Prosedur**: Saya akan langsung melakukan eksekusi perubahan file tanpa menunggu konfirmasi rencana terlebih dahulu.

### 3. Bahasa Komunikasi
- **Ketentuan**: Seluruh diskusi, penjelasan, dan log perbaikan akan menggunakan **Bahasa Indonesia**.

### 4. Lingkungan Kerja
- **OS**: Windows
- **Stack**: .NET Core 8.0 MVC / SQLite
